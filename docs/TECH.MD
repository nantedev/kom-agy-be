# Stack technique

## Backend

- **Runtime** : Node.js
- **Framework** : Express
- **Langage** : TypeScript (v6)
- **Authentification** : Better Auth
- **Validation** : Zod
- **ORM** : Prisma
- **Base de données** : PostgreSQL
- **Tests** : Vitest

## Infrastructure & Outillage

- **Hébergement frontend** : Vercel
- **Hébergement backend** : Render
- **Hébergement base de données** : Neon
- **Versioning & CI/CD** : GitHub / GitHub Actions
- **Gestion de projet & documentation** : Notion
